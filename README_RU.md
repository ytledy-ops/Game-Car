# KAZAKHSTAN LIFE SIMULATOR — Godot 4.7

Самостоятельный исходный проект с нуля. Старый HTML-прототип не используется.

## Что находится в этой сборке

Это **первый проектный вертикальный срез**: исходники подготовлены для импорта в Godot, но запуск в движке ещё не проверен. Это не готовая AAA-игра и не APK.

- 3D-сцена на Godot 4.7, мобильный рендерер Compatibility / OpenGL ES.
- Процедурно собранный городской фрагмент: S-образное дорожное кольцо, ответвления, круговое движение, тротуары, разметка, переходы, многоэтажки, советские панельные дома, частный сектор, магазины, зелёные зоны, остановки, АЗС и автомойка.
- Фасады имеют разные размеры, оттенки, окна, рамы, подоконники, балконы, входы, крыши и вывески. Повторяющиеся окна объединены через MultiMesh, чтобы не создавать тысячи отдельных узлов.
- Управляемый тестовый седан с физическим шасси `VehicleBody3D`, передним приводом, подвеской, рулением, тормозом, ручником, задним ходом, фарами, повреждением, топливом и четырьмя режимами камеры.
- Сенсорные экранные кнопки и управление с клавиатуры для тестирования.
- Разные типы трафика: легковые, такси, автобус, грузовик, минивэн и полицейская раскраска. Сейчас NPC следуют по маршруту; это ещё не полноценный ИИ перекрёстков.
- Казахстанский номер на модели и генератор номера формата `777XAH02`.
- HUD: скорость, топливо, состояние кузова, баланс и мини-карта.
- Гараж: смена цвета, установка номера, улучшения двигателя и тормозов, заправка с оплатой.
- Простая работа «Доставка»: доехать до жёлтой метки и получить 1 500 ₸.
- Реальный музыкальный поиск и воспроизведение MP3-потока через Jamendo API: название, исполнитель, обложка, сведения о лицензии, пауза, следующий/предыдущий трек, громкость, избранное и история.
- Сохранение базового прогресса, настроек радио, плейлиста, избранного, истории и состояния машины в `user://kls_save.json`.
- День/ночь и включение уличных фонарей в ночное время.

## Чего здесь пока нет

Чтобы не выдавать заглушки за готовые функции:

- Тестовый седан — процедурный блок-аут, а не точная OEM 3D-модель Chevrolet Cobalt. У него нет полноценного салона, открываемых дверей и капота.
- Остальные перечисленные марки/поколения пока не представлены в виде отдельных лицензированных 3D-моделей. Для них нужны отдельные GLB/GLTF-модели, материалы и оптимизация.
- Город — процедурный прототип из геометрии и материалов, а не законченный город с фотограмметрией, полноценными PBR texture maps и уникальными авторскими ассетами каждого здания.
- Трафик пока движется по заданному маршруту. Соблюдение светофоров, перестроения, объезд препятствий, плотная физическая реакция на столкновения и полноценные автобусные маршруты ещё не реализованы.
- Нет пешеходного ИИ, полноценных заданий такси, покупки всех моделей автомобилей, физического тюнинга дисков/обвесов/подвески и детализированной модели повреждений.
- Автомобильная аудиосистема двигателя/шин/тормозов и погодные эффекты дождя/снега пока не подключены.
- APK не приложен: среда сборки Godot не установлена в контейнере, поэтому я не могу честно назвать APK собранным или проверить запуск на твоём устройстве. Исходники находятся в этом архиве.

## Запуск на Android

1. Установи **Godot Engine 4.7.2 для Android** из официального раздела загрузок: https://godotengine.org/download/android/ .
2. Распакуй архив `KazakhstanLifeSimulator.zip` в память телефона, например в `Documents/Godot/KazakhstanLifeSimulator/`.
3. В Godot Android Editor выбери Import / Scan и укажи файл `project.godot` из этой папки.
4. Дождись импорта проекта и нажми Run.
5. Держи телефон в альбомной ориентации. Первую проверку проведи на низкой или средней графике и с небольшим числом фоновых приложений.
6. Перед экспортом APK проверь в Android Export Preset, что включено разрешение **INTERNET**: без него поиск и загрузка музыки не заработают.

Проект использует Compatibility renderer ради более широкой поддержки мобильных GPU. Поддержка зависит от графического драйвера устройства; целевой минимум Godot для этого рендерера — OpenGL ES 3.0.

## Как подключить настоящее радио

1. Открой https://devportal.jamendo.com/ и зарегистрируй приложение.
2. Получи `client_id`.
3. В игре открой **РАДИО**, вставь `client_id` в поле API KEY.
4. Введи название трека или исполнителя и нажми **НАЙТИ**.
5. Нажми ▶ у результата. Система получает MP3 stream URL из поля `audio` Jamendo, скачивает поток и воспроизводит его через `AudioStreamPlayer`.

Важные ограничения:

- Это каталог Jamendo, а не Spotify/Apple Music и не поиск по всему коммерческому музыкальному рынку. Каталог не гарантирует наличие конкретного известного исполнителя.
- Для API обязателен собственный `client_id`. В архиве нет чужого ключа.
- Jamendo возвращает поток `audio`, отдельный URL `audiodownload`, обложку и лицензию; в этом проекте используется именно поток `audio`, не ссылка на скачивание.
- Лицензии различаются от композиции к композиции. Перед публикацией игры нужно проверить лицензию каждого трека и условия API; лицензии с ограничением NC не дают права на коммерческое использование. Указывай автора и лицензию там, где это требуется.
- Музыка начинает играть после выбора трека. Закрытие панели радио не останавливает `AudioStreamPlayer`.

Документация API: https://developer.jamendo.com/v3.0/tracks

## Управление

- `W` / `↑` — газ.
- `S` / `↓` — тормоз.
- `A` / `←` и `D` / `→` — руль.
- Экранные кнопки — газ, тормоз, ручник и поворот.
- В игре: `РАДИО`, `ГАРАЖ`, `КАМЕРА`, `СВЕТ`, `D / R`, `РАБОТА`.

## Сборка APK

На Android открой проект в Godot Android Editor, затем открой Project → Export, добавь Android preset, проверь package name и разрешение INTERNET, установи export templates, если редактор попросит, и экспортируй APK. Официальная документация указывает, что при экспорте из Android Editor отдельно устанавливать OpenJDK и Android SDK не требуется; для Gradle-сборки есть дополнительные шаги. Для публикации в Google Play обычно потребуется AAB и release-подпись; для локальной установки можно собрать APK.

Официальная инструкция: https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html

## Структура

- `scenes/main.tscn` — главная 3D-сцена.
- `scripts/world.gd` — генерация мира, дорог, районов, освещения, трафика и миссии.
- `scripts/player_car.gd` — физика и процедурная модель тестового седана.
- `scripts/traffic_car.gd` — визуальные NPC-машины и движение по маршруту.
- `scripts/game_hud.gd` — HUD, сенсорное управление, гараж и мини-карта.
- `scripts/radio_panel.gd` — интерфейс автомагнитолы.
- `scripts/radio_service.gd` — поиск Jamendo, загрузка и MP3-воспроизведение.
- `scripts/save_game.gd` — локальные сохранения.
- `scripts/minimap.gd` — мини-карта.

**Статус проверки:** исходники созданы и просмотрены статически, но проект не был запущен в Godot в этой среде, так как здесь отсутствует движок и нет доступа к скачиванию исполняемого файла. Поэтому совместимость скриптов и FPS на телефоне ещё требуют проверки в Godot Android Editor.
