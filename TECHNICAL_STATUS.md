# Технический статус сборки 0.1.0

| Подсистема | Статус | Примечание |
|---|---|---|
| Godot 4.7 project | Исходники созданы | Runtime test не выполнен |
| 3D-город | Прототип готов | Процедурная геометрия, не production asset pack |
| Дорожная сеть | Прототип готов | Изогнутые сегменты, ветки, круговое движение и переходы |
| Chevrolet Cobalt | Блок-аут | Управляемый седан, не точная OEM-модель |
| Физика автомобиля | Базовая механика | VehicleBody3D, FWD, тормоз, руль, задний ход и повреждение |
| Сенсорное управление | Исходники реализованы | Требует проверки на реальном Android-экране разных пропорций |
| Трафик | Базовые NPC | Следование по маршруту; без полноценной логики перекрёстков и объезда |
| Госномера | Реализован генератор | Формат символов и региональный код; визуал номера прототипный |
| Радио | Реальная интеграция подготовлена | Нужен личный Jamendo client_id и доступ к сети; проверить на устройстве |
| Гараж | Базовые действия | Цвет, номер, мощность, тормоза и заправка |
| Экономика | Частично | Баланс, траты, доставка +1 500 ₸ |
| День/ночь | Базовый цикл | Уличные фонари включаются ночью |
| Погода | Не готово | Дождь, снег и мокрый асфальт требуют отдельного этапа |
| Сохранения | Исходники реализованы | JSON в user://; нужна runtime проверка |
| APK | Не собран | Требуется экспорт из Godot Android Editor |

## Обязательные следующие этапы

1. Запуск и устранение ошибок GDScript на Godot 4.7.2.
2. Проверка сенсорного управления, камеры, VehicleBody3D, HTTPRequest и AudioStreamMP3 на конкретном Android-устройстве.
3. Замена блок-аута Chevrolet Cobalt полноценной лицензированной GLB-моделью с салоном и PBR-текстурами.
4. Создание отдельного набора GLB-моделей остального автопарка.
5. Оптимизация города через LOD, MultiMesh, occlusion culling и чанки.
6. Полноценный дорожный AI: светофоры, полосы, перекрёстки, дистанция, объезд.
7. Пешеходы, погода, звуковые системы, расширенный тюнинг и сохранение настроек.
8. Android APK export, профилирование и тестирование на слабом/среднем устройстве.
